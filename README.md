# homebrew-tap

Personal Homebrew tap.

## Install something from here

```sh
brew tap frodi-karlsson/tap
```

Then `brew install` (formulae) or `brew install --cask` (casks):

| Name | Kind | Command |
|------|------|---------|
| [workshed](https://github.com/frodi-karlsson/workshed) | formula | `brew install frodi-karlsson/tap/workshed` |
| [happy-prs](https://github.com/frodi-karlsson/happy-prs) | cask | `brew install --cask frodi-karlsson/tap/happy-prs` |

## Maintenance

- `workshed.rb` is auto-generated by [GoReleaser](https://goreleaser.com/) on tag push from the workshed repo. Do not edit by hand.
- `Casks/happy-prs.rb` is auto-bumped by `.github/workflows/release.yml` in the happy-prs repo on tag push. Manual edits will get overwritten on the next release.
